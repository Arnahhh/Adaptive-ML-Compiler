# Start Here — Adaptive ML Compiler (corrected demo workflow)

## Run on Windows
1. Open this folder in VS Code.
2. Run `\.\build.bat` to build the original C compiler core.
3. Run `py .\adaptive_app.py` to open the desktop app.
4. Paste/open source, then click **Improve Code**. This fills the right pane with candidate SOURCE CODE and the report tab below.
5. Click **Compile & Run Improved Code** to execute that candidate. The app automatically switches the bottom panel to **Compile & Run Output**.
6. Use **Compare Original vs Improved** to compare captured output and exit status for the same input.

## Important distinctions
- The right-hand panel is always SOURCE CODE, never the program's answer.
- The report is generated by **Improve Code**; it is not runtime output.
- Runtime output appears only after **Compile & Run Improved Code**.
- Python uses Python's syntax checker, AST profile, conservative rewrites, and interpreter. The bundled legacy C compiler core's Python frontend only recognizes a subset, so it is deliberately skipped for general Python source rather than presenting a false Python syntax error. The report makes clear that the original core's KNN/IR/CFG analyses are not available for that general Python input.
- Ollama is optional. If its transform fails, the report must say so; the deterministic fallback should not be described as an AI improvement.
- Passing syntax checks does not establish equivalent behavior or performance. Compare outputs and benchmark separately.
